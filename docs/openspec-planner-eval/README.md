# OpenSpec Planner Eval

Folder for planner evaluation reports with a fixed criteria set, so future
planner runs can be compared over time.

- `report-1-primary-planner.md` — evaluation of the primary planner (the
  add-context-files-guard tasks.md as originally generated in the Manifest
  repo on 2026-11-02; that result was deleted during the 2026-11-05 replan).
- `report-2-agent-planner.md` — evaluation of a fresh same-model planning
  agent (2026-11-05) given proposal, design, specs and the calibrated rules,
  without access to any existing plan.

Criteria are identical in both reports. Scores are 0-10 per criterion.

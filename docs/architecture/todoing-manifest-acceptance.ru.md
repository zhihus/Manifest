## Границы и ограничения

- Ни один реальный подключённый проект не изменялся и не включался.
- PR, merge в `develop` и активация в рабочем проекте не выполнялись.
- Разрешение пользователя на `backlog → ready` и отмену — нормативное полномочие Main Orchestrator. Todoing технически не удостоверяет решение человека и не запрещает отдельному процессу вызывать API; это процедурная граница.
- Acceptance-тест подтверждает поведение API и документированный протокол оркестрации. Он не доказывает, что внешний runtime агентов будет соблюдать ролевые инструкции.

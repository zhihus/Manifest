# Навык tz-rezultat-hz в составе поставки Manifest

## Назначение

Manifest распространяет `tz-rezultat-hz` как независимый агентский навык для подготовки технических заданий по доработкам 1С. Навык не является частью ядра Manifest и не создаёт зависимости Manifest от 1С.

## Граница компонента

- Исходный продукт: https://github.com/zhihus/tz-rezultat-hz.
- Каталог поставки Manifest: `skills/tz-rezultat-hz/`.
- Внутренняя структура навыка переносится без переименования и выборочного сокращения: `SKILL.md`, bootstrap, Python-скрипты, references, bundle и scripts.
- Лицензия MIT и THIRD-PARTY notices исходного проекта должны сохраняться.
- Тесты bootstrap не входят в каталог навыка и размещаются отдельно в `tests/tz-rezultat-hz/`.

## Установка на Windows

Текущий интеграционный сценарий Manifest ограничен Windows x64. Навык устанавливается в каталог skills выбранного агентского harness как самостоятельная папка. Первый запуск выполняет `bootstrap.ps1` без флага режима: показывает состав полного комплекта и ничего не скачивает. Только после подтверждения пользователя выполняется `bootstrap.ps1 -Full`.

Не следует запускать bootstrap автоматически при подключении проекта: он загружает Python runtime и внешние компоненты. Установка и загрузка зависимостей требуют отдельного действия пользователя.

## Платформенная граница

Исходный продукт поддерживает Windows и Linux. Это не означает, что Manifest уже реализует и проверяет установку навыка на Linux. На текущем этапе Manifest документирует и проверяет только Windows x64. Linux-сценарий будет отдельным расширением интеграции.

## Обновление источника

Обновления берутся из публичной ветки `main` исходного репозитория. При синхронизации необходимо переносить полный каталог навыка, сохранять executable mode файлов и сверять состав с upstream. Не копировать в поставку локальные материалы, customer data или тестовые результаты.

## Проверки

- Состав каталога Manifest совпадает с upstream-каталогом навыка.
- Сохранены режимы исполняемых файлов `bootstrap.sh` и `scripts/build_binary.sh`.
- Windows bootstrap и тесты проверяются в Windows-среде.
- Внешние зависимости не вендорятся; их устанавливает штатный bootstrap.
- Тесты находятся вне `skills/tz-rezultat-hz/`.

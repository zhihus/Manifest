# Описание
Корневой документ фреймворка «Манифест». 
Содержит описание всех правил и процессов манифеста.

## 1. Инициация нового проекта

### 1.1. Действия пользователя

#### 1.1.1. Пользователь запускает инициацию манифеста сразу в папке проекта, которую он сам создал.

#### 1.1.2. Пользователь просит агента создать папку проекта и инициализировать в ней фреймворк «Манифест», предоставив путь, где будет создана папка проекта.

### 1.2. Что создаётся

#### 1.2.1. `.manifest/` — папка, признак подключения к манифесту.

#### 1.2.2. `.manifest/hooks/` — содержит действующие git-хуки манифеста.

#### 1.2.3. `.manifest/validate.sh` — скрипт верификации: проверяет файлы на соответствие правилам манифеста — наличие реквизитов, заголовки, нумерацию разделов, форматы `Version` и `Updated`.

#### 1.2.4. `.manifest/hooks/pre-commit` — срабатывает перед коммитом: запускает `validate.sh` на файлы, которые отправляются в коммит. Если файл не соответствует правилам — коммит блокируется, модель видит ошибку и исправляет файл.

#### 1.2.5. `.manifest/hooks/commit-msg` — срабатывает, когда записывается сообщение коммита: проверяет, что сообщение соответствует `commit-rules.md` (формат `<type>(<scope>): <subject>`). Если сообщение не соответствует — коммит блокируется, модель переписывает сообщение.

#### 1.2.6. Активация хуков: `git config core.hooksPath .manifest/hooks`.

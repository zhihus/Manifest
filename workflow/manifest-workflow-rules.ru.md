# Описание
Корневой документ фреймворка «Манифест». 
Содержит описание всех правил и процессов манифеста.

## 1. Инициация нового проекта

### 1.1. Что делает пользователь

* Пользователь запускает инициацию сразу в папке проекта, которую он сам
  создал.
* Либо пользователь просит агента создать папку проекта и инициализировать
  в ней фреймворк «Манифест», предоставив путь, где будет создана папка
  проекта.

### 1.2. Что создаётся

* `.manifest/` — помечает проект как подключённый к Манифесту.
* `.manifest/hooks/` — папка git-хуков.
* `.manifest/validate.sh` — скрипт верификации (запланирован).
* `.manifest/hooks/pre-commit` — вызывает `validate.sh` на staged-файлах
  (запланирован).
* `.manifest/hooks/commit-msg` — проверяет сообщение коммита по
  `commit-rules.md` (запланирован).
* Активация хуков: `git config core.hooksPath .manifest/hooks`.

# Описание
Корневой документ фреймворка «Манифест»: правила и процессы манифеста.

## 1. Инициация нового проекта

### 1.1. Действия пользователя

#### 1.1.1. Запуск инициации

Пользователь запускает инициацию манифеста с помощью скилла
`manifest-init` в папке проекта, которую он сам создал.

#### 1.1.2. Создание папки агентом

Пользователь просит агента создать папку проекта и инициализировать в
ней фреймворк «Манифест», предоставив путь к папке.

### 1.2. Артефакты инициации проекта

#### 1.2.1. `.manifest/`

Папка, признак подключения к манифесту.

#### 1.2.2. `.manifest/hooks/`

Папка, содержит действующие git-хуки манифеста.

#### 1.2.3. `.manifest/validate.sh`

Скрипт верификации: проверяет файлы на соответствие правилам
манифеста.

#### 1.2.4. `.manifest/hooks/pre-commit`

Перед коммитом запускает скрипт `validate.sh` для проверки файлов,
которые отправляются в коммит.

#### 1.2.5. `.manifest/hooks/commit-msg`

Срабатывает, когда записывается сообщение коммита: проверяет, что
сообщение соответствует правилам файла `commit-rules.md`.

# Правила именования файлов и папок

> **Status: draft**
> **Type: document**
> **Version: 1.0.0**
> **Updated: 2026-11-07**

# Описание
Универсальные правила именования файлов и папок проекта, подключённого к
фреймворку «Манифест».

## 1. Правила

### 1.1. Имена только на английском

### 1.2. kebab-case, нижний регистр, через тире, без пробелов

### 1.3. Имя файла (не папки) всегда содержит суффикс языка: `en` или любой другой по требованию пользователя.

## 2. Примеры

### 2.1. Файлы — правильно

✅ `naming-rules.en.md`
✅ `naming-rules.ru.md`

### 2.2. Файлы — неправильно

❌ `File Naming Rules.en.md`
❌ `fileNamingRules.en.md`
❌ `файл-именования.en.md`
❌ `naming-rules.md`
❌ `naming-rules.EN.md`

### 2.3. Папки — правильно

✅ `workflow`
✅ `docs`
✅ `my-project`

### 2.4. Папки — неправильно

❌ `MyFolder`
❌ `my_folder`
❌ `папка`

# Правила структуры файлов

> **Status: draft**

Универсальные правила структуры Markdown-документов любого проекта,
подключённого к фреймворку «Манифест».

## 1. Минимальная структура

* Каждый Markdown-файл имеет структуру. Минимум: заголовок — начинается
  с `#` — и статусная строка.

## 2. Статусная строка

* Статусная строка — ровно одно слово: `**Status: draft**`. Больше ничего
  в неё не добавляется.
* Фиксированный набор статусов (три базовых):
  * `draft` — в разработке;
  * `approved` — утверждён;
  * `archived` — архив.

## 3. Нумерация разделов

* Разделы и подразделы нумеруются иерархически, через точку, по глубине:
  `1` → `1.1`, `1.2` → `1.2.1` (каждый уровень добавляет один компонент).

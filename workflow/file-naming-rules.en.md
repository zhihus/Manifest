# File Naming Rules

> **Status: draft**
> **Version: 1.0.0**
> **Updated: 2026-11-07**

# Description
Universal file naming rules for a project connected to the Manifest
framework.

## 1. Rules

### 1.1. Names in English only

### 1.2. kebab-case, lowercase, hyphen-separated, no spaces

### 1.3. File names always carry a language suffix: `en`, or any other at the user's request

## 2. Examples

### 2.1. Correct

✅ `file-naming-rules.en.md`
✅ `file-naming-rules.ru.md`

### 2.2. Incorrect

❌ `File Naming Rules.en.md`
❌ `fileNamingRules.en.md`
❌ `файл-именования.en.md`
❌ `file-naming-rules.md`
❌ `file-naming-rules.EN.md`

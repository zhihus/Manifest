# Правила изменения метаданных файла

> **Status: draft**
> **Type: document**
> **Version: 1.0.0**
> **Updated: 2026-11-07**

# Описание
Правила изменения блока метаданных файла-документа проекта,
подключённого к фреймворку «Манифест».

## 1. Метаданные

Блок метаданных файла-документа состоит из четырёх реквизитов:

> **Status: draft**
> **Type: document**
> **Version: 1.0.0**
> **Updated: 2026-11-07**

## 2. Версия

2.1. Версия — трёхкомпонентное число: `X.Y.Z`.

2.2. Версия расположена в документе, в шапке, в метаданных: > **Version: X.Y.Z**.

2.3. X (major) — ломающие изменения: существующее содержание удалено или изменено по смыслу.

2.4. Y (minor) — добавлено новое содержание, существующее расширено.

2.5. Z (patch) — уточнения, исправления формулировок, опечатки.

2.6. Новый документ в статусе `draft` получает версию `1.0.0`.

2.7. Документ в статусе `draft` не меняет версию при изменении.

2.8. Версия меняется только для документа в статусе `approved`.

2.9. Изменение статуса `draft` → `approved` или `approved` → `archived` не меняет версию.

2.10. В статусе `archived` любое изменение версии запрещено.

## 3. Дата

3.1. Дата в блоке метаданных: `> **Updated: YYYY-MM-DD**` — дата последнего изменения.

3.2. Дата обновляется при каждом изменении.

## 4. Тип

4.1. Тип файла указан в метаданных: `> **Type: document**`.

## 5. Статус

5.1. Статус документа указан в метаданных: `> **Status: draft**`, `> **Status: approved**` или `> **Status: archived**`.

# Описание
Правила изменения блока метаданных файла-документа проекта,
подключённого к фреймворку «Манифест».

## 1. Метаданные

Метаданные: версия, дата, тип файла и статус расположены в шапке
документа.

> **Status: draft**
> **Type: document**
> **Version: 1.0.0**
> **Updated: 2026-11-07**

## 2. Версия

### 2.1. Формат

2.1.1. Версия — трёхкомпонентное число: `X.Y.Z`.

### 2.2. Повышение

2.2.1. X (major) — ломающие изменения: существующее содержание удалено или изменено по смыслу.

2.2.2. Y (minor) — добавлено новое содержание, существующее расширено.

2.2.3. Z (patch) — уточнения, исправления формулировок, опечатки.

### 2.3. Статус

2.3.1. Новый документ в статусе `draft` получает версию `1.0.0`.

2.3.2. Документ в статусе `draft` не меняет версию при изменении.

2.3.3. Версия меняется только для документа в статусе `approved`.

2.3.4. Изменение статуса `draft` → `approved` или `approved` → `archived` не меняет версию.

2.3.5. В статусе `archived` любое изменение версии запрещено.

## 3. Дата

3.1. Дата `> **Updated: YYYY-MM-DD**` — дата последнего изменения.

3.2. Дата обновляется при каждом изменении.

## 4. Тип

4.1. Тип файла: `> **Type: document**`.

4.2. Правила изменения типа не предусмотрены.

## 5. Статус

5.1. Статус документа изменяется по требованию пользователя.

5.2. Автоматическое изменение статуса не предусмотрено.

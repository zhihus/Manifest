# Правила структуры файлов

# Метаданные
> **Status: draft**
> **Type: document**
> **Version: 1.0.0**
> **Updated: 2026-11-08**

# Описание
Универсальные правила структуры Markdown-документов проекта,
подключённого к фреймворку «Манифест».

## 1. Общие правила структуры файла
1.1. Каждая строка файла не может быть длиннее 100 символов.

## 2. Описание шапки документа

```
1.# <имя заголовка>
Описание: заголовок, название файла, уровень 1, строка 1,
  рекомендация по длине: до 5 слов, до 35 символов;
  шаблон: <# <имя заголовка>>
```

```
2.# Метаданные
Описание: заголовок, блок метаданных, уровень 1, строка 3;
  шаблон: <# <имя метаданных>>; <имя метаданных> = "Метаданные".
Изменение значений метаданных описано в документе `file-metadata-change-rules.ru.md`.
```

```
3.> **Status: draft**
Описание: метаданные, статус, строка 5, шаблон: > **<имя>: <значение>** ; значение: одно из списка
Список значений (расширяемый): draft — в разработке, approved — утверждён, archived — архив
```

```
4.> **Type: document**
Описание: метаданные, тип файла, строка 6,
  шаблон: > **<имя>: <значение>** ; значение: одно из списка
Список значений (расширяемый): document — Markdown-документ
```

```
5.> **Version: 1.0.0**
Описание: метаданные, версия, строка 7,
  шаблон: > **<имя>: <значение>** ;
  значение: трёхкомпонентное число X.Y.Z, где X — major,
  Y — minor, Z — patch
```

```
6.> **Updated: 2026-11-07**
Описание: метаданные, дата, строка 8,
  шаблон: > **<имя>: <значение>** ;
  значение: дата в ISO-формате YYYY-MM-DD
```

```
7.# Описание
Описание: заголовок, раздел описания, уровень 1, строка 10;
  шаблон: <# <имя описания>>; <имя описания> = "Описание".
Правила структуры Markdown-документов проекта, подключённого к фреймворку «Манифест».
```

```
8.Короткий абзац, описывающий суть документа
Описание: текст, описание, строка 11, рекомендация по длине: до 20 слов, до 100 символов
```

```
9.## 1. <название раздела>
Описание: заголовок, раздел, уровень 2, строка 13,
  рекомендация по длине: до 5 слов, до 35 символов;
  значение: <название раздела>
```

## 1. Нумерация разделов

* Разделы и подразделы нумеруются иерархически, через точку, по глубине:
  `1.` → `1.1.`, `1.2.` → `1.2.1.` (каждый уровень добавляет один компонент).

## 2. Подразделы с метками

* Если раздел содержит несколько частей с метками (например, правильно /
  неправильно), метки — отдельные строки текста под одним заголовком
  раздела, а не отдельные подзаголовки с меткой в тексте заголовка.

  Правильно:

  ```
  ### 2.1. Файлы

  Правильно

  ✅ `naming-rules.en.md`
  ✅ `naming-rules.ru.md`

  Неправильно

  ❌ `File Naming Rules.en.md`
  ❌ `fileNamingRules.en.md`
  ```

  Неправильно:

  ```
  ### 2.1. Файлы — правильно

  ✅ `naming-rules.en.md`
  ✅ `naming-rules.ru.md`

  ### 2.2. Файлы — неправильно

  ❌ `File Naming Rules.en.md`
  ❌ `fileNamingRules.en.md`
  ```

# Правила структуры файлов

# Метаданные
> **Status: draft**  
> **Type: document**  
> **Version: 1.0.0**  
> **Updated: 2026-11-08**

# Описание
Универсальные правила структуры Markdown-документов проекта,
подключённого к фреймворку «Манифест».

## 1. Исключения для файла правил структуры

### 1.1. Правило описания строк

```
Описание:
Под каждой строкой обязательно описание строки по шаблону —
для обработки алгоритмами.
```

### 1.2. Описание в текстовом блоке

```
Описание:
Описание строки заключено в текстовый блок — этого нет в других файлах.
```

### 1.3. Структура

```
Описание:
Файл оформляется по разделам 2, 3, 4 самого же себя.
```

## 2. Общие правила структуры файла

### 2.1. Длина строки
```
Описание:
Каждая строка файла не может быть длиннее 100 символов.
```

### 2.2. Нумерация разделов

```
Описание:
Разделы и подразделы нумеруются иерархически: 1. → 1.1. → 1.1.1.
Каждый уровень добавляет один компонент с точкой.
Уровень номера равен уровню заголовка:
1. — ##, 1.1. — ###, 1.1.1. — ####.
```

### 2.3. Универсальный формат описания строки

```
Описание:
тип=<...>, назначение=<...>, строка=<N>, обязательность=<да|нет>,
  уровень=<...|—>, шаблон=<...|—>, значение=<...|—>, длина=<...|—>
Поля со знаком "—" пропущены: поле не применимо к этой строке.
```

### 2.4. Тип

```
Описание:
Вид строки: заголовок, метаданные, текст.
```

### 2.5. Назначение

```
Описание:
Что представляет строка (название файла, статус, версия).
```

### 2.6. Номер

```
Описание:
Номер строки в документе.
```

### 2.7. Обязательность

```
Описание:
Обязательна ли строка: да / нет.
```

### 2.8. Уровень иерархии

```
Описание:
Только для заголовков.
```

### 2.9. Шаблон

```
Описание:
Паттерн строки; <...> — подставляемое значение.
```

### 2.10. Значение

```
Описание:
Допустимое значение: произвольное, одно из списка, фиксированное.
```

### 2.11. Длина

```
Описание:
Рекомендация по длине: до N слов / до M симв.
```


## 3. Описание шапки документа

### 3.1. Заголовок файла

```
Описание:
тип=заголовок, назначение=название файла, строка=1, обязательность=да,
  уровень=1, шаблон=<# <имя заголовка>>, значение=произвольное, длина=до 5 слов / до 35 симв.
```

### 3.2. Метаданные

```
Описание:
тип=заголовок, назначение=блок метаданных, строка=3, обязательность=да,
  уровень=1, шаблон=<# <имя метаданных>>, значение=Метаданные, длина=—
Изменение значений метаданных описано в документе `file-metadata-change-rules.ru.md`.
```

### 3.3. Статус

```
Описание:
> **Status: draft**
тип=метаданные, назначение=статус, строка=5, обязательность=да,
  уровень=—, шаблон=<> **<имя>: <значение>**>, значение=одно из списка, длина=—
Список значений (расширяемый): draft — в разработке, approved — утверждён, archived — архив
```

### 3.4. Тип

```
Описание:
> **Type: document**
тип=метаданные, назначение=тип файла, строка=6, обязательность=да,
  уровень=—, шаблон=<> **<имя>: <значение>**>, значение=одно из списка, длина=—
Список значений (расширяемый): document — Markdown-документ
```

### 3.5. Версия

```
Описание:
> **Version: 1.0.0**
тип=метаданные, назначение=версия, строка=7, обязательность=да,
  уровень=—, шаблон=<> **<имя>: <значение>**>, значение=X.Y.Z, длина=—
```

### 3.6. Дата

```
Описание:
> **Updated: 2026-11-07**
тип=метаданные, назначение=дата, строка=8, обязательность=да,
  уровень=—, шаблон=<> **<имя>: <значение>**>, значение=ISO YYYY-MM-DD, длина=—
```

### 3.7. Раздел описания

```
Описание:
# Описание
тип=заголовок, назначение=раздел описания, строка=10, обязательность=да,
  уровень=1, шаблон=<# <имя описания>>, значение=Описание, длина=—
Правила структуры Markdown-документов проекта, подключённого к фреймворку «Манифест».
```

### 3.8. Текст описания

```
Описание:
Короткий абзац, описывающий суть документа
тип=текст, назначение=описание, строка=11, обязательность=нет,
  уровень=—, шаблон=—, значение=произвольное, длина=до 20 слов / до 100 симв.
```

### 3.9. Заголовок раздела

```
Описание:
## 1. <название раздела>
тип=заголовок, назначение=раздел, строка=13, обязательность=да,
  уровень=2, шаблон=<## <название раздела>>, значение=произвольное, длина=до 5 слов / до 35 симв.
```

  уровень=2, шаблон=<## <N>. <название раздела>>, значение=произвольное,
  длина=до 5 слов / до 35 симв.
```

```
### 1.1. Формат версии

  длина=до 5 слов / до 35 симв.

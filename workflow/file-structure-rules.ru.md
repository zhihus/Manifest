# Описание
Универсальные правила структуры Markdown-документов проекта,
подключённого к фреймворку «Манифест».

## 1. Исключения для файла правил структуры

### 1.1. Правило описания строк

```
Описание:
Описания строк по шаблону обязательны только в этом файле —
для обработки алгоритмами. В других файлах описания строк
**НЕ** ставятся.
```

### 1.2. Описание в текстовом блоке

```
Описание:
Описание строки заключено в текстовый блок — этого нет в других файлах.
```

### 1.3. Структура

```
Описание:
Файл оформляется по разделам 2, 3, 4, 5, 6 самого же себя.
```

### 1.4. Разметка регионов

```
Описание:
Разметка регионов (шапка/тело/подвал) и поле `регион` —
индивидуальная особенность этого файла: она нужна, чтобы было
понятно, где что. В других файлах поле `регион` не заполняется.
```

## 2. Общие правила структуры файла

### 2.1. Стандарт Markdown

```
Описание:
Структура файлов строится на стандарте Markdown.
```

### 2.2. Нумерация разделов

```
Описание:
Нумерация применяется только к регионам тело и подвал; на шапку
не распространяется.
Разделы и подразделы нумеруются иерархически: 1. → 1.1. → 1.1.1.
Каждый уровень добавляет один компонент с точкой.
Нумерация сквозная: подвал продолжает нумерацию тела
(## 1. → ## 2. Примеры).
Уровень 1 (#) — только в шапке: название файла, # Метаданные, # Описание.
Уровень 2 (##) — разделы тела; подразделом быть не может.
Уровни 3+ (###, ####) — подразделы раздела (тела или подвала).
```

### 2.3. Логическая строка

```
Описание:
Одна логическая строка может занимать несколько физических строк:
перенос — часть той же строки, а не отдельная строка.
Заголовки не переносятся: заголовок — всегда одна физическая строка.
К переносимым строкам относятся: текст описания (3.8), текст под
заголовком (4.2), строки примеров (5.5).
```

### 2.4. Пустые строки

```
Описание:
Пустые строки — визуальные разделители; в описании строк
не участвуют и алгоритмами игнорируются.
```

### 2.5. Универсальный формат описания строки

```
Описание:
назначение=<...>, строка=<N>, обязательность=<да|нет>,
  уровень=<...|—>, шаблон=<...|—>, формат=<...|—>,
  вид значения=<произвольное|одно из списка|фиксированное|—>,
  значения=<...|—>, длина=<...|—>,
  количество=<1|не ограничено|—>, юникод символ=<✅ | ❌ |—>,
  список=<расширяемый | фиксированный |—>,
  примечание=<...|—>, регион=<шапка|тело|подвал|—>
Поля со знаком "—" пропущены: поле не применимо к этой строке.
Юникод символ: ✅ — правильно, ❌ — неправильно.
```

### 2.6. Назначение

```
Описание:
Что представляет строка (название файла, статус, версия).
```

### 2.7. Номер

```
Описание:
Номер строки в документе.
```

### 2.8. Обязательность

```
Описание:
Обязательна ли строка: да / нет.
Обязательность наследуется: если раздел необязательный, все его
подразделы тоже необязательны. Обязательный раздел может содержать
необязательные подразделы.
```

### 2.9. Уровень иерархии

```
Описание:
Только для заголовков.
```

### 2.10. Шаблон

```
Описание:
Паттерн строки; <...> — подставляемое значение.
```

### 2.11. Формат

```
Описание:
Формат строки: ISO YYYY-MM-DD, X.Y.Z, —.
```

### 2.12. Вид значения

```
Описание:
Вид значения: произвольное, одно из списка, фиксированное.
```

### 2.13. Длина

```
Описание:
Рекомендация по длине: до N слов / до M симв.
```

### 2.14. Количество

```
Описание:
Сколько таких строк допустимо: 1, не ограничено.
```

### 2.15. Юникод символ

```
Описание:
Юникод символ в строке: ✅ — правильно, ❌ — неправильно.
— — символа в строке нет.
```

### 2.16. Примечание

```
Описание:
Дополнительный контекст строки, который не выражается другими
полями; — — примечания нет.
```

### 2.17. Регион

```
Описание:
Регион документа: шапка, тело, подвал.
Шапка — заголовок файла, # Метаданные, # Описание и текст описания.
Тело — нумерованные разделы.
Подвал — раздел «Примеры».
— — регион не применим.
```

## 3. Описание шапки документа

  вид значения=произвольное, значения=—,

  список=—, примечание=—, регион=шапка

## 4. Описание тела документа

### 4.1. Однострочное текстовое поле

```
Описание:
назначение=заголовок с правилом, строка=<N>, обязательность=да,
  уровень=2, шаблон=<## <N>. <правило>>, формат=—,
  вид значения=произвольное, значения=—,
  длина=до 100 симв., количество=не ограничено,
  юникод символ=—, список=—,
  примечание=правило укладывается в одну строку заголовка;
  уровни 3–4 аналогичны: ###, ####, регион=тело
```

### 4.2. Многострочное текстовое поле

```
Описание:
назначение=текст под заголовком, строка=<N>, обязательность=да,
  уровень=—, шаблон=—, формат=—,
  вид значения=произвольное, значения=—,
  длина=до 50 слов / до 300 симв., количество=не ограничено,
  юникод символ=—, список=—,
  примечание=правило не укладывается в одну строку;
  заголовок краткий (2–3 слова) с номером;
  переносится, см. 2.3, регион=тело
```

## 5. Описание примеров

### 5.1. Раздел примеров

```
Описание:
назначение=раздел, строка=<N>, обязательность=нет,
  уровень=2, шаблон=<## <N>. Примеры>, формат=—,
  вид значения=фиксированное, значения=Примеры, длина=—,
  количество=1, юникод символ=—, список=—,
  примечание=—, регион=подвал
```

### 5.2. Подзаголовок

```
Описание:
назначение=подраздел, строка=<N>, обязательность=нет,
  уровень=3, шаблон=<### <N>.<M>. <название раздела>>, формат=—,
  вид значения=произвольное, значения=—,
  длина=до 5 слов / до 35 симв., количество=не ограничено,
  юникод символ=—, список=—,
  примечание=позиция переменная; группирует примеры по категориям,
  регион=подвал
```

### 5.3. Правильно

```
Описание:
назначение=метка примера, строка=<N>, обязательность=нет,
  уровень=—, шаблон=—, формат=—,
  вид значения=фиксированное, значения=Правильно, длина=—,
  количество=1, юникод символ=—, список=—,
  примечание=обязательна при наличии примеров; раздел примеров
  необязательный, регион=подвал
```

### 5.4. Неправильно

```
Описание:
назначение=метка примера, строка=<N>, обязательность=нет,
  уровень=—, шаблон=—, формат=—,
  вид значения=фиксированное, значения=Неправильно, длина=—,
  количество=1, юникод символ=—, список=—,
  примечание=—, регион=подвал
```

### 5.5. Строки примеров

```
Описание:
назначение=пример, строка=<N>, обязательность=нет,
  уровень=—, шаблон=<✅ | ❌ <пример>>, формат=—,
  вид значения=произвольное, значения=—, длина=—,
  количество=не ограничено, юникод символ=✅ | ❌,
  список=—, примечание=длинный пример переносится, см. 2.3,
  регион=подвал
Строки примеров подчиняются ближайшей предыдущей метке.
```

## 6. Примеры

### 6.1. Правильный

```
# Правила именования файлов и папок

# Метаданные
> **Status: approved**  
> **Type: document**  
> **Version: 1.0.0**  
> **Updated: 2026-11-07**  

# Описание
Универсальные правила именования файлов и папок проекта, подключённого к
фреймворку «Манифест».

## 1. Правила

### 1.1. Имена только на английском.

### 1.2. kebab-case, нижний регистр, через тире, без пробелов.

### 1.3. Имя файла (не папки) всегда с суффиксом языка — код ISO 639-1, нижний регистр: `en`, `ru`.

## 2. Примеры

### 2.1. Файлы

Правильно

✅ `naming-rules.en.md`
✅ `naming-rules.ru.md`

Неправильно

❌ `File Naming Rules.en.md`
❌ `fileNamingRules.en.md`
❌ `файл-именования.en.md`
❌ `naming-rules.md`
❌ `naming-rules.EN.md`

### 2.2. Папки

Правильно

✅ `workflow`
✅ `docs`
✅ `my-project`

Неправильно

❌ `MyFolder`
❌ `my_folder`
❌ `папка`
```

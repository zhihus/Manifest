# Правила именования файлов

> **Status: draft**
> **Version: 1.0.0**
> **Updated: 2026-11-07**

# Описание
Универсальные правила именования файлов проекта, подключённого к
фреймворку «Манифест».

## 1. Правила

### 1.1. Имена на английском

### 1.2. kebab-case, нижний регистр, через тире, без пробелов

### 1.3. Имя файла всегда содержит суффикс языка: `en` или любой другой по требованию пользователя

## 2. Примеры

### 2.1. Правильно

✅ `file-naming-rules.en.md`
✅ `file-naming-rules.ru.md`

### 2.2. Неправильно

❌ `File Naming Rules.en.md`
❌ `fileNamingRules.en.md`
❌ `файл-именования.en.md`
❌ `file-naming-rules.md`
❌ `file-naming-rules.EN.md`

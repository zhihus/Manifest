# Правила версионирования файлов

> **Status: draft**
> **Type: document**
> **Version: 1.0.0**
> **Updated: 2026-11-07**

# Описание
Правила версионирования файлов-документов проекта, подключённого к
фреймворку «Манифест».

## 1. Формат версии

1.1. Версия — трёхкомпонентное число: `X.Y.Z`.

1.2. Версия расположена в документе, в шапке, в метаданных: > **Version: X.Y.Z**.

## 2. Повышение версии

2.1. X (major) — ломающие изменения: существующее содержание удалено или изменено по смыслу.

2.2. Y (minor) — добавлено новое содержание, существующее расширено.

2.3. Z (patch) — уточнения, исправления формулировок, опечатки.

## 3. Версия и статус

3.1. Новый документ в статусе `draft` получает версию `1.0.0`.

3.2. Документ в статусе `draft` не меняет версию при изменении.

3.3. Версия меняется только для документа в статусе `approved`.

3.4. Переход `draft` → `approved` не меняет версию.

3.5. В статусе `archived` — версия заморожена, повышение версии запрещено.

## 4. Дата

4.1. Дата в теле, в блоке метаданных: `> **Updated: YYYY-MM-DD**` — дата последнего изменения.

4.2. Дата обновляется при каждом изменении.

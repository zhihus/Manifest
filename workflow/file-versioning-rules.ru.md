# Правила версионирования файлов

> **Status: draft**
> **Version: 1.0.0**
> **Updated: 2026-11-07**

# Описание
Правила версионирования файлов-документов любого проекта, подключённого к
фреймворку «Манифест».

## 1. Формат версии

### 1.1. Версия — трёхкомпонентное число: `X.Y.Z`.

### 1.2. Версия находится в теле, в блоке метаданных: `> **Version: X.Y.Z**`.

## 2. Повышение версии

### 2.1. X (major) — ломающие изменения: правило удалено или изменено по смыслу.

### 2.2. Y (minor) — добавлены новые правила, существующие расширены.

### 2.3. Z (patch) — уточнения, исправления формулировок, опечатки.

## 3. Дата

### 3.1. Дата в теле, в блоке метаданных: `> **Updated: YYYY-MM-DD**` — дата последнего изменения.

### 3.2. Дата обновляется при каждом повышении версии.

## 4. Начальная версия

### 4.1. Новый документ начинается с `1.0.0`.

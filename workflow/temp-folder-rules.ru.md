# Описание
Универсальные правила временной папки проекта. Применяются в любом
проекте, подключённом к Манифесту.

## 1. Размещение и имя

### 1.1. Имя и расположение

Папка называется `temp` — только маленькими буквами. Она находится в
корне проекта.

### 1.2. Git

Папка добавлена в `.gitignore`: её содержимое никогда не попадает в
коммиты.

## 2. Писать можно всё, удалять — ничего

### 2.1. Запись

Агент может писать в `temp/` что угодно в любой момент: скрипты,
промежуточные артефакты, черновики. Спрашивать разрешение не нужно.

### 2.2. Запрет удаления

Агент не удаляет в `temp/` ничего: ни свои файлы, ни файлы других
агентов. Даже если файл кажется устаревшим или лишним, агент оставляет
его на месте.

### 2.3. Кто чистит

Папку чистит пользователь — вручную или по своей явной просьбе агенту.
Сама инициатива уборки со стороны агента запрещена.

## 3. Запрет команд удаления через консоль

### 3.1. Почему

Команды удаления (`rm`, `Remove-Item` и аналоги) опасны: они требуют
подтверждения пользователя и прерывают процесс на неопределённое
время.

### 3.2. Что делать вместо

Вместо команды удаления агент останавливается и сообщает пользователю.
Удаление выполняет пользователь или агент — но только по явной просьбе
пользователя.

## 4. Блок для субагентов

### 4.1. Единый источник текста

Следующий блок — единый источник текста о папке `temp/` для
определений субагентов. Его копируют дословно, без пересказа.

```text
In the project there is a `temp/` folder for temporary files — write
anything you need there, no permission needed. Delete nothing inside
it. Do not use console deletion commands (rm, Remove-Item): stop and
report to the user instead.
```
